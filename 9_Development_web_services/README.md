# Coordinate Transformer — Автоматизированная система преобразования координатных данных

Практическая работа №10. Локальная клиент-серверная система для преобразования
координатных данных из Excel-файлов.

- **Бэкенд** — FastAPI (`http://127.0.0.1:8000`)
- **Фронтенд** — Streamlit (`http://localhost:8501`)
- **Обмен** — REST API, вход: Excel-файл, выход: отчёт в формате Markdown

Всё работает **локально**, без внешних сервисов и облачных платформ.

## Возможности

- Загрузка Excel-файлов (`.xlsx`, `.xls`) через веб-интерфейс
- Три режима преобразования координат:
  - Декартовы → Полярные (`x, y` → `r, θ`)
  - Полярные → Декартовы (`r, θ` → `x, y`)
  - Аффинное преобразование (`x, y` → `x', y'`)
- Настройка единиц измерения углов (градусы/радианы) и точности
- Предварительный просмотр входных данных и результатов
- Автоматическая генерация отчёта в формате Markdown
- Скачивание отчёта одним кликом
- Опционально: запуск через Docker Compose

---

## Архитектура

Оба процесса запускаются **на одной машине** и общаются через `localhost`.

**Почему такая схема:**

- Масштабируемость — бэкенд можно усилить без пересборки фронтенда
- Разделение ответственности — обработка данных отделена от интерфейса
- Гибкость — один бэкенд может обслуживать несколько фронтендов

## Запуск

Нужно **два терминала** — отдельно для бэкенда и фронтенда.

### Терминал №1 — бэкенд

```bash
cd backend
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Проверка:

- <http://127.0.0.1:8000/> → JSON с приветствием
- <http://127.0.0.1:8000/docs> → Swagger UI (интерактивная документация)

### Терминал №2 — фронтенд

```bash
cd frontend
streamlit run app.py
```

Streamlit автоматически откроет браузер на <http://localhost:8501>.

## Формат входных данных

Excel-файл с заголовками в первой строке. Ожидаемые столбцы
зависят от режима преобразования:

| Режим | Обязательные столбцы |
|---|---|
| `cartesian_to_polar` | `x`, `y` |
| `polar_to_cartesian` | `r`, `theta` |
| `affine` | `x`, `y` |

**Пример (декартовы координаты):**

| x | y |
|---|---|
| 100.0 | 200.0 |
| -50.5 | 33.2 |
| 0.0 | 0.0 |

**Пример (полярные координаты):**

| r | theta |
|---|---|
| 223.6 | 63.43 |
| 60.4 | 146.7 |

---

## Режимы преобразования

### Декартовы → Полярные

```
r = √(x² + y²)
θ = atan2(y, x)     # в градусах или радианах
```

### Полярные → Декартовы

```
x = r · cos(θ)
y = r · sin(θ)
```

### Аффинное преобразование

```
x' = a·x + b·y + c
y' = d·x + e·y + f
```

Параметры `a, b, c, d, e, f` задаются в боковой панели фронтенда.

## API бэкенда

### `GET /`

Информация о сервисе.

**Ответ:**
```json
{
  "message": "Coordinate Transformation API работает",
  "endpoints": {
    "/9_Development_web_services/": "POST: загрузка Excel и преобразование координат"
  }
}
```

### `POST /9_Development_web_services/`

Загружает Excel-файл, выполняет преобразование и возвращает отчёт.

**Content-Type:** `multipart/form-data`

**Параметры формы:**

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `file` | File | — | Excel-файл (`.xlsx`, `.xls`) |
| `mode` | str | `cartesian_to_polar` | Режим преобразования |
| `angle_unit` | str | `degrees` | `degrees` или `radians` |
| `precision` | int | `6` | Знаков после запятой |
| `affine_a` | float | `1.0` | Коэффициент a |
| `affine_b` | float | `0.0` | Коэффициент b |
| `affine_c` | float | `0.0` | Коэффициент c |
| `affine_d` | float | `0.0` | Коэффициент d |
| `affine_e` | float | `1.0` | Коэффициент e |
| `affine_f` | float | `0.0` | Коэффициент f |

**Пример запроса:**

```bash
curl -X POST "http://127.0.0.1:8000/transform-coordinates/" \
     -F "file=@test_cartesian.xlsx" \
     -F "mode=cartesian_to_polar" \
     -F "angle_unit=degrees" \
     -F "precision=4"
```

**Пример ответа:**

```json
{
  "markdown_report": "# Отчет о преобразовании координатных данных\n\n...",
  "processed_data": [
    {"x": 100.0, "y": 200.0, "r": 223.6068, "theta": 63.4349}
  ],
  "filename": "coordinate_report_20260929_120000.md"
}
```

**Ошибки:**

| Код | Причина |
|---|---|
| `400` | Неподдерживаемый формат файла / отсутствуют обязательные столбцы |
| `500` | Внутренняя ошибка обработки |

## Тестирование

### Генерация тестовых данных

```bash
python generate_test_data.py
```

Будут созданы:
- `test_cartesian.xlsx` — 100 записей с полями `x`, `y`
- `test_polar.xlsx` — 100 записей с полями `r`, `theta`

### Сценарий тестирования

1. Запустите бэкенд и фронтенд (см. раздел [Запуск](#запуск)).
2. Откройте <http://localhost:8501>.
3. Убедитесь, что статус API — «доступен».
4. Загрузите `test_cartesian.xlsx`.
5. Выберите режим «Декартовы → Полярные».
6. Установите точность `4`, единицы — градусы.
7. Нажмите «Выполнить преобразование».
8. Проверьте:
   - появление столбцов `r` и `theta` в результатах;
   - корректность значений (например, `x=100, y=0` → `r=100, theta=0`);
   - возможность скачать отчёт.

### Проверка API через curl

```bash
curl -X POST "http://127.0.0.1:8000/transform-coordinates/" \
     -F "file=@test_cartesian.xlsx" \
     -F "mode=cartesian_to_polar" \
     -F "angle_unit=degrees" \
     -F "precision=4"
```
