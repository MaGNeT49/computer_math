# Coordinate Transformer

Автоматизированная система преобразования координатных данных.

## Возможности

- Загрузка Excel-файлов с координатами.
- Режимы преобразования:
  - Декартовы → Полярные (`x, y` → `r, theta`)
  - Полярные → Декартовы (`r, theta` → `x, y`)
  - Аффинное преобразование (`x, y` → `x_new, y_new`)
- Настройка единиц измерения углов и точности.
- Генерация отчёта в формате Markdown.
- Скачивание отчёта.
