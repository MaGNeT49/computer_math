# Оптимальный объезд точек на реальной дорожной сети

Веб-приложение на Streamlit: пользователь ищет адреса, добавляет их в список (первая точка - депо),
выбирает критерий (расстояние / время / комфорт) и получает оптимальный маршрут курьера на карте.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Состав

- `graph_utils.py` - загрузка графа OSMnx, CSR-матрицы весов, алгоритм Дейкстры (SciPy),
  задача коммивояжера (полный перебор и жадный алгоритм), восстановление маршрута;
- `app.py` - интерфейс (боковая панель: поиск адреса, список точек, критерий, коэффициенты комфорта;
  основная область: карта Folium и сведения о маршруте).

Для поиска адресов используется Nominatim (не чаще одного запроса в секунду), для карты - OpenStreetMap.
